# Product website / 产品网站

A dependency-free bilingual static site with fictional screenshots and a privacy policy. / 无依赖的中英双语静态网站，使用合成截图并提供隐私政策。

Local preview / 本地预览: `npm run preview`, then `http://127.0.0.1:4173/site/`.

GitHub Pages deploys only this directory through `.github/workflows/pages.yml`. The extension and internal notes are not part of the website artifact. / GitHub Pages 工作流仅部署本目录，扩展和内部笔记不会部署到网站。

Public URLs / 公开地址:

- Chrome Web Store / Chrome 应用商店: https://chromewebstore.google.com/detail/follow-garden-x-following/njapleffcdeikalapdhkgkpbbhdnlmcg

- https://iruochen.github.io/follow-garden/
- https://iruochen.github.io/follow-garden/privacy.html

The site stores only a language preference. Hosting logs are governed by GitHub’s policies. / 本站只存储语言偏好，托管日志适用 GitHub 政策。
