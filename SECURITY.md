# Security Policy

[English](SECURITY.md) · [简体中文](SECURITY.zh-CN.md)

## Supported versions

Only the latest published 0.1.x release receives fixes. This early release does not provide a guaranteed support period.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/iruochen/follow-garden/security/advisories/new). Do not disclose exploitable details, credentials or private user data in public issues.

Include the affected version, minimal synthetic reproduction, potential impact and suggested mitigation. Test only accounts and systems you own or are authorized to use. Do not send live cookies or API keys.

Relevant risks include untrusted profile content, CSV injection, account isolation, credential handling, permissions and mistaken unfollow actions. We may pause a release or affected capability while investigating.
