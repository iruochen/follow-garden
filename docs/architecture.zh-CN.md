# 架构

[English](architecture.md) · [简体中文](architecture.zh-CN.md)

关注花园由 Manifest V3 扩展和静态产品网站组成，没有开发者后端或生产依赖。

## 组件

- `extension/ui/`：双语管理页与工具栏 popup，通过限定的扩展消息接口发起操作。
- `background.js`：初始化设置、读取器、会话监听及本地服务。
- `service.js` / `domain.js`：按账号隔离状态、关系证据、保护和待处理资格、临时预览与持久化。
- `session.js` / `connection.js` / `request-observer.js` / `list-transport.js`：临时观察 X 会话、核实身份，在关联 X 标签执行固定请求（读取及独立确认的单用户拉黑）。
- `twitter-api.js` / `read-settings.js`：可选 Key 存储、独立第三方认证、顺序排队与分页。
- `runner.js`：确认后的取关任务、逐项关系复核、暂停、取消及结果不明的恢复规则。

- `block.js`：单用户拉黑、保护与账号核实、持久化不确定结果和只读复核。

## 数据流

顶部刷新依次读取关注与关注者。每页先展示在内存预览中，取消恢复旧快照。只有明确结束标记才能判定完整，不能靠人数少或空页推断；错误时按规则保留并标记部分结果。

免费模式复用 X 登录会话，关注与关注者均直接分页读取资料，每页请求最多 200 位。第三方完整刷新从资料生成 ID，不额外请求同一 ID 列表；第三方请求受节流与供应商计费约束。

## 约束

- ID 保持字符串，缺失数据保持未知。
- 不完整粉丝集不能证明未回关；保护和关系分类独立。
- 保护与未知账号不能进入取关候选。
- 读取期间及写操作前核实账号，身份变化即停止。
- 写操作必须明确确认，结果未知的请求不能自动重发。
- 认证不进入快照、导出或日志；可选供应商 Key 使用独立的扩展可信存储。
- 不执行远程 JavaScript，响应只作为数据处理，头像限定 X 图片 CDN。

## 验证

`npm test` 使用合成数据验证领域、会话、第三方、服务及任务；`npm run check` 检查公开文档、manifest、素材和双语覆盖；`npm run package` 生成可复现扩展包。真实接口和商店审核属于独立验证环节。
