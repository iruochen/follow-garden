# 隐私政策

[English](privacy.md) · [简体中文](privacy.zh-CN.md)

生效日期：2026 年 10 月 8 日。本政策适用于关注花园扩展及静态产品网站。

## 数据与用途

扩展为管理 X 关注关系而处理账号 ID、名称、用户名、简介、粉丝/关注数量、头像 URL 和关系字段。本地保存快照及其时间/完整度、保护备注、待处理选择、任务结果与语言偏好。不处理私信、通讯录或支付资料。

## 认证与接收方

主动连接 X 并授权后，仅从关联标签观察所需请求头。授权、CSRF 与操作标识短暂保留于后台内存，十分钟后过期，不写日志、不导出、不持久化。请求使用浏览器已有 X Cookie，代码不读取其值，不要求提供 X 密码或 Token。

读取及确认后的取关请求直接发往 `x.com` 或 `api.x.com`。头像通过 HTTPS `pbs.twimg.com` 加载，不发送页面 referrer。账号记录不发送到开发者服务器。不采集通用浏览历史，仅观察完成核心用途所需的有限 X 请求。

可选 TwitterAPI.io 模式仅在主动读取时，将自备 API Key、目标用户名或 ID 与分页参数直接发送到 `api.twitterapi.io`。不传 X Cookie 或会话凭据，不通过第三方执行取关。供应商按自身政策处理请求及收费。

## 存储与控制

快照、整理记录、任务和语言保存在本地浏览器，不用 Chrome 同步或开发者云备份。当前资料快照及按账号区分的整理/任务记录保留至替换或清除。关联标签 ID 使用会话存储。

供应商 Key 默认使用仅扩展可访问的会话存储；选择记住后在本机扩展 local 存储中未加密保存。Key 不进入快照和导出，可以独立清除，也可随全部数据清除。

设置中可导出 CSV 或清除账号记录、任务及 Key。清除会断开 X 并恢复合成示例，保留语言偏好；不能删除已经另存的文件，也不撤销 X 已完成的操作。新取关任务需明确确认，结果未知的请求不会自动重发。

## 网站与其他用途

不出售数据，不用于广告、分析、信用评估或放贷。静态网站只存语言偏好，无分析服务或表单；GitHub Pages 可能按 GitHub 隐私政策处理普通访问日志。X 和 TwitterAPI.io 的请求适用各自政策。

## 联系与更新

一般问题通过 [GitHub Issues](https://github.com/iruochen/follow-garden/issues) 反馈，不附凭据或私人账号记录。安全报告遵循 [安全政策](../SECURITY.zh-CN.md)。数据处理变化时更新政策及生效日期。

关注花园为独立产品，与 X Corp. 不存在隶属关系。
